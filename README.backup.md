### Lab 5.1 – Docker Storage (Volumes, Bind Mounts et tmpfs)

#### Objectif
Découvrir les mécanismes de stockage Docker et comprendre la persistance des données.

#### 1. Stockage sans volume
- Création d'un conteneur PostgreSQL sans volume.
- Insertion de données dans une table.
- Après suppression et recréation du conteneur, les données ont disparu.

#### 2. Docker Named Volume
- Création du volume `lab51-data`.
- Association au conteneur PostgreSQL.
- Après suppression et recréation du conteneur avec le même volume, les données sont toujours présentes.

#### 3. Bind Mount
- Création d'un fichier `index.html` sur Ubuntu.
- Montage du dossier local dans un conteneur Nginx avec l'option `:ro`.
- Lecture autorisée et modification refusée.

#### 4. tmpfs Mount
- Création d'un conteneur Nginx avec un montage tmpfs.
- Création et lecture d'un fichier temporaire.
- Vérification avec `df -h`.
- Les données sont stockées temporairement en mémoire.
